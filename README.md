# Positive Prompt Tabs

Forge Neoのポジティブプロンプトを、タブで切り替える拡張機能です。
良かった文章を残しながら、人物・構図・背景の候補を試せます。

```text
[ 人物A ︙ ][ 人物B ︙ ][ 背景 ︙ ] [＋] [↶]
┌────────────────────────────────────────┐
│ 選択中のポジティブプロンプト             │
└────────────────────────────────────────┘
```

## 機能

- 入力欄の上辺に密着したタブ。初回はタブ1・2・3から開始
- タブの追加・名前変更・複製・削除・削除の取り消し
- ドラッグで左右に並べ替え。青い線で挿入位置を表示
- 文章・タブ名・並び順・選択中のタブを自動保存
- txt2imgとimg2imgで独立したタブを管理
- 生成ボタンを押した時のタブの文章で生成
- 📋でスタイルを適用する際、共通ネガティブへの同じスタイル文章の重複追加を防止

## インストール

1. Neoの **Extensions（拡張機能）→ Install from URL** を開きます。
2. 次のリポジトリURLを入力してインストールします。

   ```text
   https://github.com/dr1610/sd-webui-positive-prompt-tabs.git
   ```

3. **Neoを再起動**し、ブラウザーを再読み込みします。

手動の場合は、このリポジトリをNeoの `extensions/sd-webui-positive-prompt-tabs` に配置してください。
本体ファイルの書き換えや追加Pythonパッケージのインストールは不要です。

## 操作

| 操作 | 方法 |
|---|---|
| タブ切り替え | タブ名をクリック |
| 新しいタブ | ＋をクリック |
| 名前変更・複製・削除 | 各タブの︙ |
| 並べ替え | タブ名をつかんで左右へドラッグ、または︙の左右移動 |
| 削除の取り消し | ↶、削除後の「元に戻す」、または︙の復元 |
| 生成 | Neo標準の生成ボタン、またはCtrl+Enter |

最後の1タブは削除できません。タブにフォーカスして左右矢印・Home・Endでも切り替えられます。
名前変更はEnterで保存、Escでキャンセル。削除履歴はページを閉じるまで保持します。

## 保存と生成

保存先はブラウザーの **localStorage** です。同じブラウザー・同じ接続先で復元されます。
ポート、localhostと127.0.0.1、ブラウザープロファイルが違う場合は別の保存先になります。
ブラウザーデータを消去すると失われるため、重要な文章は別途控えてください。
複数のブラウザータブで同じNeoを編集した場合は、最後の保存が優先されます。

標準の入力欄をそのまま使用します。PNG情報の転送や補完などで反映された文章も、選択中のタブに取り込みます。
初回の文章はタブ1へ引き継ぎます。起動時に保存内容と異なる文章が既に入力されている場合は、別タブへ退避します。

生成に送信された文章は、後からタブを切り替えても変わりません。
ネガティブプロンプト・Hires専用プロンプト・その他の生成設定はタブ別には保存しません。

## 📋の重複防止

ネガティブ欄は共通なので、各タブで同じスタイルを適用すると通常はネガティブ文章が繰り返し追加されます。
本拡張は、完全なスタイル文章が既にある場合、その追加を省略します。ポジティブへの適用とスタイル選択の解除はNeo標準の処理です。

- 標準の📋と、スタイル編集ダイアログ内の📋が対象
- 個々のタグの一括削除は行わず、既にある重複も自動削除しません
- スタイル文章の一部だけが一致する場合や表記が異なる場合は、重複と判定しません
- 生成時のスタイル適用処理は変更しません

## 対応と制限

Forge Neo / Gradio 4.40.0 / Windowsで検証しています。その他のWebUIでの互換性は未確認です。
Neo標準の文章Undo履歴は入力欄単位のため、タブごとには分かれていません。タブをまたぐCtrl+Zに注意してください。

無効化はNeoの拡張機能画面から行い、Neoを再起動してください。ブラウザー内の保存データは残ります。

## 開発・検証

```sh
npm install
npm test
```

ブラウザーテストはMicrosoft Edgeを使用します。`PPT_NEO_URL`を設定すると、起動中のNeoでも配置・切り替え・生成送信データを検証します。
テストは独立したブラウザープロファイルで実行されます。生成リクエストはブラウザー内で遮断し、GPU生成は実行しません。

スタイル重複防止のテストは、Neoのソースを指定して実行します。

```sh
python tests/style_guard.py /path/to/Forge-Neo
```
